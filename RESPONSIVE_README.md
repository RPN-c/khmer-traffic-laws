# Cambodia Driving Rules App — Web/Responsive Update

## How to run on browser (Chrome/Edge/etc.)

This project didn't include a `web/` folder yet because that's generated by the
Flutter SDK itself. To enable web support, run this once inside the project folder:

```bash
flutter create . --platforms=web
```

This adds a `web/` directory (with `index.html`, icons, manifest) without touching
your existing `lib/` code. After that, just run:

```bash
flutter pub get
flutter run -d chrome
```

## What changed for responsiveness

A new file `lib/responsive.dart` was added with:

- **`Responsive.gridColumns(context)`** — 2 columns on phones, 3 on tablets,
  4–5 columns on desktop, for the home screen's module grid.
- **`Responsive.pagePadding(context)`** — scales side padding from 16px (mobile)
  up to 48px (large desktop) so content doesn't hug the edges on wide windows.
- **`Responsive.maxContentWidth(context)`** — caps content width (700–900px)
  on tablet/desktop so text and cards don't stretch edge-to-edge on a wide
  browser window — mimics a "reading width" container like most responsive
  web apps use.
- **`ResponsiveCenter`** — centers content and applies the max-width constraint.
  Used for items that need their *natural* height (header bars, nav bars).
- **`ResponsiveCenterExpand`** — same centering/max-width behavior, but fills
  all available space first. Used wherever the wrapped content contains an
  `Expanded` widget that needs a bounded height (e.g. Study screen body,
  the exam's scrollable question area, Home screen body).

## Screens updated

| Screen | Change |
|---|---|
| `home_screen.dart` | Grid columns scale with screen width; content centered with max width on desktop |
| `study_screen.dart` | List content centered with max width; search bar and list adapt padding |
| `exam_screen.dart` | Header/progress bar/nav bar stay full-width visually but their *content* is centered; question area centered and capped in width so it's comfortable to read on large screens |
| `result_screen.dart` | Score card, banners, and review list centered with max width on wide screens |

## Notes

- All Khmer text rendering (Google Fonts Noto Sans Khmer) works identically
  on web — no changes needed there.
- Asset loading (`assets/data/*.json`, `assets/images/sign/*.png`) works the
  same way on web since Flutter bundles them at build time.
- No layout overflow issues: `ResponsiveCenterExpand` uses `SizedBox.expand`
  to safely provide bounded height to any `Expanded`/`Column` children inside,
  which avoids the common "RenderBox was not laid out" error when centering
  scrollable layouts.
