# Khmer Traffic Laws Driving App

A Flutter mobile app for learning and practicing Cambodia traffic rules, road signs, and driving knowledge.

## Overview

This app helps users study and review key traffic law topics through a clean interface with:

- category-based learning
- image-based road sign recognition
- practice exam mode
- result review and answer explanations
- responsive layout for mobile devices

## Features

- Study traffic rules by category
- Review road signs and related rules
- Take timed or guided exam sessions
- See results with question-by-question feedback
- Built with Flutter and Dart for cross-platform support

## Tech Stack

- Flutter
- Dart
- GetX for state management
- Google Fonts
- Local JSON data for traffic questions and road sign assets

## Project Structure

- `lib/` – application logic, screens, controllers, and models
- `assets/data/` – question and rule data in JSON format
- `assets/images/sign/` – traffic sign images
- `test/` – widget and app tests

## Getting Started

1. Install Flutter SDK
2. Clone the repository
3. Run:

```bash
flutter pub get
flutter run
```

## Common commands

```bash
flutter test
flutter analyze
flutter build apk
```

## Notes

This app is designed around Cambodia traffic knowledge and includes road sign data and rule categories commonly used for driver education and exam preparation.
